A QUICK START
A model in a few lines.
Declare elements and relationships in model. Add a view when you want to control the composition.
architecture "My system" {
  model {
    person user "User"
    service api "API"
    relation calls user -> api "Calls"
  }
  view overview "Overview" {
    place user at (0, 0)
    place api at (340, 0)
    route calls { curve rounded }
  }
}
Types
person, system, application, service, component, database, queue, interface, capability, process, artifact, node, package
Make it yours
Use description, technology and icon attributes. Add style overrides, ports, waypoints and SVG paths in a view.
